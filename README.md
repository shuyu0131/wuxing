入职第一周，你收到一封来自「综合管理部」的系统通知——
没有导师带教，没有流程指引，只有一堆你从没见过的处境：
深夜 23:47 的消息、抢功的同事、推不掉的酒局、写反了的会议纪要，
还有一句你反复咀嚼却读不懂的：「这个方案先放着，不着急。」

**悟性 · 职场修炼场**把这些瞬间做成了一道道题。
每一道都来自真实职场，每一次选择都有逐项拆解：
为什么这么选是专业的，为什么那么选是灾难。
玩的是游戏，练的是真本事。

## 游戏特色

- **真实情境，逐项拆解** — 52 道原创职场情商题，覆盖向上管理、同事相处、拒绝的艺术、会议汇报、饭局应酬、危机处理、办公室政治、自我提升八个维度。四个选项各有「为什么对 / 为什么错」，外加一句可复用口诀（例如「拒绝公式：做不到 X，但可以做到 Y 和 Z」）。
- **行测式思维训练** — 40 道数字推理、逻辑判断、文字推理与场景计算题，附完整解法与口诀（例如「数列卡壳第一步：先做差」），备考行测也能顺手练。
- **错题本会记住你** — 答错的题主动回访，补悟成功一道 +15 悟性；清空错题本解锁成就「补悟圆满」。答对才涨分，错题才是涨功力最快的地方。
- **AI 实时情景（实验）** — 接入你自己的大模型（智谱 GLM-4-Flash 免费），**自定义行业、岗位、主题与风格**，实时生成全新情境并自动入库，题目永不重复。
- **联网排行榜 + 玩家出题** — 悟性榜实时比拼；任何人都能出题，署名进入所有人的题库，被作答与点赞越多排名越高，前十名获得金 / 银 / 铜牌出题人称号。
- **场景化呈现** — 题目按内容自动装进对应容器：企业微信群聊、OA 会议纪要、内部邮件、监控告警、日程提醒、在线测评，像真实工作流，而不是题库。
- **老板键，防露馅** — 任何时候按 Esc，整页秒变一张只读的「部门绩效指标跟踪表」，键盘输入全拦截，用完即走，不留痕迹。
- **单文件 · 零依赖 · 隐私安全** — 游戏本体是一个 HTML 文件，双击即玩；数据只存在你的浏览器里，不上传任何服务器。

## 一键部署

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fshuyu0131%2Fwuxing)

点击按钮 → 确认 → 等待构建，约 30 秒后你将获得一个公网地址，排行榜、玩家出题、AI 代理全部就绪，手机与同事均可访问。

| 配置 | 必需 | 说明 |
|---|---|---|
| （无） | — | 零配置即可部署运行；排行榜为临时数据，实例重启后清零 |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | 可选 | 在 Vercel → Storage 添加免费的 **Upstash Redis** 集成即自动注入，榜单全局持久 |
| `AI_KEY` / `AI_MODEL` | 可选 | 服务端共享大模型 Key（也可按厂商分 `AI_KEY_ZHIPU` 等），玩家无需各自填写 |
| `AI_URL` | 可选 | 自定义模型网关（OpenAI 兼容），配合 provider=`custom` 使用 |

> 安全设计：AI 上游是**代码内硬编码的厂商白名单**（智谱 / 硅基流动 / DeepSeek / Kimi / 通义 / OpenAI / OpenRouter），客户端只能传 provider 标识，不存在可注入的接口地址；题目与成绩接口带结构校验、查重与限流；游戏不收集任何个人信息。

## 玩法

**入职测评（一次性）**：6 题定初始 EQ / IQ 基线，只涨这两个分数，不给悟性、不记错题。

**修行一日（主玩法）**：7 个真实时段（08:50 早会前 → 23:00 下班路上），每个时段优先抽该时段高发的题型——早会是向上管理，会议室是会议汇报，加班中是危机处理。每题答对得悟性，答错扣一点「心态」（3 点用完提前结算），错题进错题本。

**每日一练**：8 题，题序由当天日期决定（同一天所有人题目相同，且不可刷），连对 6 题以上累积连击天数。

**晋级试炼**：悟性达标后可发起。8 题混合，每题限时 25 秒，答对 6 题晋升。失败不扣任何东西，不限次数。

**连击倍率**：连对越多单题悟性越高（`8 + 难度×3 + min(连击,10)×2`），答错清零。所以稳住比贪刀赚得多。

**十个职级**：见习生 → 试用新人 → 正式员工 → 业务骨干 → 组长 → 主管 → 经理 → 总监 → 合伙人 → 打工魂·悟道者。

**十二项成就**：一日无过、妙语连珠、一气呵成、七日不辍、补悟圆满、百题斩……

## 老板键（防露馅）

按 **Esc**，整页变成一个只读的「2026年度部门绩效指标跟踪表.xlsx」Excel 窗口：

- 标题栏（X 图标 + 「只读」徽标 + 窗口按钮）、功能区（剪贴板 / 字体 / 对齐方式 / 数字 / 样式 / 单元格 / 编辑，全部真实图标与字形）、名称框 + 编辑栏（`=SUM(E2:E13)*0.98`）、带行号列标的指标表、工作表标签、状态栏（就绪 · 只读 · 平均值 / 计数 / 求和 · 缩放 100%）。
- **固定模板，不可自定义、不可编辑**：全页 `user-select:none`、无任何输入控件；键盘上除 Esc 外全部拦截（Ctrl+C/A/P/S/F/U、输入、粘贴、拖拽、右键菜单一律屏蔽）；状态栏标明「只读 · 建议以只读方式打开」——从行为上解释了为什么它不能被编辑。
- 伪装期间游戏 DOM 被隐藏，标签页标题同步变为 Excel 文件名；再按 Esc 即返回。

## 技术与隐私

- **Element Plus 设计语言**：官方色板与组件规范 + 52 个官方 SVG 图标内联（sprite），页面零 emoji、零外部请求。
- **数据全部本地**：进度存于浏览器 localStorage（`wuxing_save_v3`），排行榜/出题仅在开启服务端或部署 Vercel 后按需提交昵称与成绩。
- **服务端零依赖**：`server.mjs` 与 `api/*`（Vercel 函数）共用 `lib/common.mjs` 校验库，仅用 Node 内置模块。
- **AI 上游白名单硬编码**：客户端无法注入接口地址；自定义网关需部署方修改 `api/ai.js` 顶部常量或配置 `AI_URL`。
